# TDG Configuration

## Project Information
- Language: TypeScript
- Framework: Node.js (npm)
- Test Framework: Vitest

## Build Command
npx tsc --noEmit

## Test Command
npx vitest run

## Single Test Command
npx vitest run <path/to/file.test.ts> -t "<test name>"

## Coverage Command
npx vitest run --coverage

## Test File Patterns
- Test files: *.test.ts
- Test directory: tests/
